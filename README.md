# IDTN-WEB

Landing Page Resmi PT Infinix Delapan Teknologi Nusantara (IDTN) — Solusi Infrastruktur Jaringan Telekomunikasi, DWDM, Transmisi Serat Optik, dan Data Center Interconnect.

## Dokumentasi & Spesifikasi SDLC
Seluruh rancangan spesifikasi rekayasa profesional tersedia di [`.kiro/specs/idtn-landing-page/`](./.kiro/specs/idtn-landing-page/):
- **01-PRD**: [Product Requirement Documentation](./.kiro/specs/idtn-landing-page/01-PRD.md) — Kebutuhan produk, persona B2B, dan arsitektur informasi.
- **02-TRD**: [Technical Requirement Documentation](./.kiro/specs/idtn-landing-page/02-TRD.md) — Arsitektur sistem, 11 peran audit SDLC v2.0, dan verifikasi standar MDN.
- **03-AFD**: [App Flow Documentation](./.kiro/specs/idtn-landing-page/03-AFD.md) — Perjalanan pengguna, alur presentasi slide DWDM (ala t8.ru), dan siklus form inquiry.
- **04-DBD**: [Design Brief Documentation](./.kiro/specs/idtn-landing-page/04-DBD.md) — Design tokens, light theme, tipografi teknis, dan kartu sertifikasi (ala tkm.co.id).
- **05-BSD**: [Backend Schema Documentation](./.kiro/specs/idtn-landing-page/05-BSD.md) — Decoupled Local JSON CMS, validasi skema Zod, dan kontrak API inquiry.
- **06-IPD**: [Implementation Plan Documentation](./.kiro/specs/idtn-landing-page/06-IPD.md) — Rencana kerja bertahap Fase 1–8, matriks ketertelusuran, dan gates rilis.

## Tech Stack
- **Framework**: Vite 6 + React 19 + TypeScript 5.8
- **Styling**: Tailwind CSS v4 (Light Theme Precision)
- **Interactive Slides**: Swiper 11 + GSAP 3.12
- **Data Validation**: Zod v3
- **Iconography**: Lucide React
